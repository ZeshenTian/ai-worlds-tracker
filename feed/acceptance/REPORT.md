# WorldFeed 验收报告

2026 年 11 月 24 日，使用本机 Google Chrome 158.0.8127.37 验收生产构建。桌面和移动测试各自启动独立的浏览器进程与窗口，移动测试使用 390 × 844 触控视口。全部六项通过。

| 规格第 7 节 | 实测结果 |
| --- | --- |
| 构建与类型检查 | 在 `feed/` 运行 `npm run build` 成功，TypeScript 零错误，Vite 输出包含 HTML、脚本、样式、数据、封面和镜像的 `dist/`。 |
| 单活 iframe | NOVA LANCER 与 After the tide 分别在同域镜像中渲染真实 canvas。试玩时仅有 1 个世界 iframe，退出或点击下一条后为 0。 |
| 滚轮与帧外退出 | 使用 Chrome 输入事件发送含惯性尾段的滚动手势，一次仅切过一条。方向键和 J/K 均生效。iframe 获得焦点后，顶部退出和帧外下一条仍可用。 |
| 三层体验 | 两个本地镜像的已加载资源均成功响应。Francis Turbine Explorer 在真实跨域 iframe 中渲染 canvas；测试将真实导航延后 4.8 秒，确认 4 秒恢复链接在加载中出现、加载后仍可用。Glimmerpine 展示实景图，点击按钮在新标签打开作者的 itch.io 试玩页。 |
| 中英切换 | 用带中日文标题的实际案例验证英文页面与详情抽屉，刷新与直链均保持英文。对全部 898 条的英文标题、署名、摘要、模型、技术栈、工作流及技能扫描通过。 |
| 响应式、直链与错误 | 桌面 1440 × 900、移动 390 × 844 的页面宽度分别为 1440、390 像素。移动端触摸切换与底部抽屉通过。两个视口的受测界面与 iframe 合计 0 console error、0 page error、0 HTTP 4xx/5xx。 |

当前快照有 898 条作品，872 条符合推荐流条件。其中全库含 2 个同域镜像、470 个按响应头判为可嵌入的外站、426 个外链条目。外站的运行时验收抽测了上表列出的作品。原作自身的界面语言由其作者控制。
